# Cyber Security Basics: Terminal Authentication Gateway

A lightweight, foundational Python automation script designed to simulate a localized security gateway interface. This project focuses on mastering input/output data handling and implementing conditional evaluation matrices.

##  Core Functionality
* **Dynamic Interaction:** Prompts the console operator for session credentials using native stream inputs.
* **Conditional Logic Tree:** Deploys a strict validation matrix (`if/elif/else`) checking both attributes simultaneously via logical conjunctions (`and`).
* **Session Handling:** Safely filters incoming strings to grant access to authorized operator tokens while flagging invalid attempts.

##  Execution
To test this authentication logic locally, run the script inside your terminal or Virtual Machine environment:

```bash
python3 gatekeeper.py
